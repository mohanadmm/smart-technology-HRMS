# Employee Documents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Every task also follows `ponytail`, `andrej-karpathy-skills:karpathy-guidelines` and `docs/coding-standards.md`.

> **Commands:** backend commands run from the worktree root as `docker compose exec app …`. The worktree may need its own throwaway DB and containers; **the controller may substitute the container invocation** (project name, compose file, env) and tells the implementer which one to use. Tests always run on `hrms_test` (`tests/TestCase.php` refuses anything else).

**Goal:** HR uploads, views, replaces, edits and deletes an employee's document files on the employee page; managers see only the list (kind and expiry); the received date is gone.

**Architecture:** `employee_documents` gains `original_name`, `mime`, `size_bytes` (no path column; the path is derived) and loses `received_at` and the `(employee_id, kind)` unique. A new `EmployeeDocuments` application service owns upload/edit/delete/file lookup on the private `local` disk; a new `EmployeeDocumentController` exposes four routes guarded by the new `employee_document.view|edit` permissions plus `employee.scope`. The frontend's Documents tab moves to its own file (`pages/employee-documents.tsx`): a `DataList`, an upload dialog that shrinks big photos, and a viewer that rebuilds the fetched Blob from the stored mime.

**Tech Stack:** Laravel 13 / PHP 8.4, PostgreSQL 17, PHPUnit 12, `Storage` (local disk); React 19 + TS, Tailwind 4, Radix, react-i18next, Vitest + Testing Library (jsdom).

**Spec:** `docs/superpowers/specs/2026-11-03-employee-documents-design.md` (approved; owner decisions D1–D10). Read it with this plan; Part 3 review fixes are binding.

## Global Constraints

- Allowed types: `File::types(['pdf','jpg','jpeg','png','webp'])->max(10240)`; store the **detected** mime; never SVG, HTML, Office, archives, HEIC.
- Limits: app 10 MB < PHP `upload_max_filesize=12M` ≤ `post_max_size=13M` < nginx 40 MB.
- Storage: disk `local` (`storage/app/private`), `'serve' => false`; path `employee-documents/{employee_id}/{id}.{ext}`, `ext` from mime: `application/pdf→pdf`, `image/jpeg→jpg`, `image/png→png`, `image/webp→webp`. No `path` column, no Docker volume, nothing on the `public` disk.
- Grants: `employee_document.view.all` → developer, hr, ceo; `employee_document.view.own` → nobody; `employee_document.edit.all` → developer, hr. Routes name only `employee_document.view` / `employee_document.edit`; exactly one `permission:` per route.
- Without `employee_document.view`, a document in `GET /employees/{id}` is only `id`, `kind`, `expires_at`. With it: plus `original_name`, `mime`, `size_bytes`, `note`, `created_at`, `uploader_name`. Never `received_at`, never a path.
- Replace = new row + soft-delete of the old one, in one transaction; delete = model `delete()` (soft); files are never erased.
- `original_name`: strip U+202A–202E, U+2066–2069 and control characters (`\p{Cc}`), cut to 255 chars.
- Served file: `Content-Type` = stored mime, `X-Content-Type-Options: nosniff`, `Cache-Control: private, no-store`, Content-Disposition = original base name + detected extension.
- Frontend: Blob rebuilt with an allow-listed type from the stored mime (never `res.blob().type`); `<img>` only for `image/*`, `<iframe>` only for `application/pdf`; revoke every object URL.
- "Expires soon" = 30 days, a constant (`EXPIRY_SOON_DAYS`), not a setting.
- Photo shrink: JPEG/PNG/WEBP over 1.5 MB → `createImageBitmap(file, { imageOrientation: 'from-image' })` → white-filled canvas, 2400 px long edge → `toBlob('image/jpeg', 0.85)` → keep the smaller, rename `.jpg`, original on any error. Order: check type → shrink → check size.
- `accept="image/jpeg,image/png,image/webp,application/pdf"`, no `capture`.
- No new dependency (no pdf.js). Every UI string ar + en; Arabic strings containing Latin letters go in `allowed` in `frontend/src/locales/locales.test.ts`.
- Fixtures: `UploadedFile::fake()` and tiny generated bytes only; no real document or personal data.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A database row whose file is missing on disk** (a DB restored without `backend/storage/app/private`, D6): `/file` must answer 404 envelope, not 500 or an empty 200. Test in Task 4.
2. **A file name that is only control/bidi characters, or has no base name (`.pdf`)**: stored name `document`, download name `document.{ext}`; a 300-character name is cut to 255. Test in Task 2.
3. **A 0-byte file** (finfo says `application/x-empty`): 422 with the type message, no row, no file. Test in Task 2.
4. **`replaces` pointing at a deleted document or another employee's document**: 404, and the just-stored new file is removed. Test in Task 2.
5. **Expiry boundaries**: expires today → "Expires today" (amber), in 30 days → amber, in 31 days → no badge, yesterday → "Expired" (red). Test in Task 9.
